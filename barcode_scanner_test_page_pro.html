Decision Checklist

A scanner is usually sufficient if:

  • it reads GS1 DataMatrix
  • it reads GS1-128
  • it outputs a usable AIM prefix
  • it preserves or maps group separator correctly
  • it works consistently as keyboard wedge or similar input
  • it supports FO pilot scenarios without broken output
